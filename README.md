# Portfolio de Rayane Akroun

Portfolio réalisé dans le cadre du BTS SIO (projet fil rouge).

## Objectif

Présenter mon parcours, mes compétences et mes réalisations en tant que
développeur backend / API.

## Thème / charte graphique

Thème sobre et professionnel, palette volontairement réduite :

- Fonds : gris très clair (`#F5F7FA`) en alternance avec du blanc (`#FFFFFF`), cartes blanches
- Accent : bleu (`#2F80ED`) — titres, boutons, liens, bordures
- Texte : gris foncé (`#1F2937`)

## Technologies

- HTML5
- CSS3
- Bootstrap 5 (grille responsive)
- JavaScript
- Git / GitHub / GitHub Pages

## Structure

- `index.html` : page principale
- `css/style.css` : styles et charte graphique
- `js/main.js` : scripts
- `assets/images/` : captures des projets, photo de profil
- `assets/documents/cv.pdf` : CV à ajouter
